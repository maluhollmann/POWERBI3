# POWERBI3
Nesse mini-projeto 3 visa responder questões de negócios de Marketing. Utilizando o dataset da DSA e aprendendo com o mesmo, buscamos criar 4 visões sobre os dados, sendo elas:
• Visão do Cliente
• Visão do Comportamento de Compra do Cliente
• Visão da Performance das Campanhas de Marketing
• Visão dos Padrões de Compra no Ponto de Venda (País)

Com esse mini-projeto pude aprender mais sobre os KPI's, o que são Outliers e como resolve-los, e descobri mais gráficos e funções DAX.
